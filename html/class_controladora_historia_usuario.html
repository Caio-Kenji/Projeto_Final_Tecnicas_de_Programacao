Detailed Description

Controladora de apresentação para entidade HistoriaUsuario.

Responsável por exibir o menu de gerenciamento de histórias de usuário, ler os dados informados pelo usuário e solicitar ao serviço correspondente as operações sobre histórias de usuário.
