Detailed Description

Classe base abstrata para todos os domínios do sistema.

Esta classe fornece a estrutura fundamental para qualquer domínio, garantindo que todo valor atribuído seja validado antes do armazenamento. O método setValor() lança exceção se o formato for inválido.

Invariant
O atributo 'valor' sempre armazena uma string válida para o domínio.
