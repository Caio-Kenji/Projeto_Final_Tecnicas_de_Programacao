Detailed Description

Representa em qual etapa do fluxo de trabalho uma tarefa se encontra.

  • "A FAZER" : Tarefa aguardando na fila, nenhum trabalho realizado
  • "FAZENDO" : Tarefa sendo executada neste momento, trabalho em andamento
  • "FEITO" : Tarefa completa, trabalho finalizado

@exceptions

Exceptions
invalid_argument"Estado invalido." se o valor não for exatamente um dos três strings definidos (case-sensitive).
Note
A transição entre estados segue a ordem natural: A FAZER → FAZENDO → FEITO (não é possível retroceder ou pular fases)
