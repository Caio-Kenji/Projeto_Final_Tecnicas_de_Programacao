Domínio que representa o papel/função de uma pessoa no projeto Scrum.

Domínio que representa o papel/função de uma pessoa no projeto Scrum. A classe Papel define e valida os três papéis possíveis que um usuário pode assumir dentro de um projeto Scrum:

  • DESENVOLVEDOR: Responsável pela implementação técnica
  • MESTRE SCRUM: Facilitador do processo, remove impedimentos
  • PROPRIETARIO DE PRODUTO: Responsável pelo backlog e requisitos
Invariant
O valor armazenado é sempre uma das três strings válidas.

@exceptions

Exceptions
std::invalid_argument"Papel invalido. Opcoes validas: ..." quando o valor fornecido não corresponde a nenhum papel permitido.
Note
A comparação é case-sensitive e não considera acentuação conforme requisito não funcional 12.
try {
Papel dev("DESENVOLVEDOR"); // Válido
Papel scrum("MESTRE SCRUM"); // Válido
Papel po("PROPRIETARIO DE PRODUTO"); // Válido
Papel invalido("GERENTE"); // Lança exceção
} catch (const invalid_argument& e) {
cout << e.what() << endl;
}
