Detailed Description

Representa um plano de sprint dentro de um projeto.

Um sprint é um período de tempo fixo onde um conjunto de histórias de usuário é executado. Esta classe gerencia:

  • Identificação única do sprint (código)
  • Capacidade em dias (1-365)
  • Período de execução (data início e fim)
  • Relação com o projeto pai
  • Associação com histórias de usuário
Invariant
O código do plano de sprint é único no sistema.
A capacidade deve estar entre 1 e 365 dias.
A data de início deve ser anterior à data de término.
A soma das estimativas das histórias ≤ capacidade.
Note
As regras de negócio sobre capacidade vs estimativas são verificadas nos métodos associarHistoria() e desassociarHistoria().
See also
Codigo, Tempo, Data, HistoriaUsuario
