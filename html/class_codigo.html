Detailed Description

Domínio para identificadores alfanuméricos com formato fixo de 5 caracteres.

Armazena e valida strings que seguem a seguinte estrutura:

  • Posição 1 e 2: duas letras maiúsculas (A a Z)
  • Posição 3, 4 e 5: três dígitos numéricos (0 a 9)
Note
Este formato é comumente utilizado para identificação de tarefas, projetos ou itens no sistema.

@exceptions

Exceptions
invalid_argument"Codigo invalido." se:
  • A string não tiver exatamente 5 caracteres
  • O 1º ou 2º caractere não for letra maiúscula
  • O 3º, 4º ou 5º caractere não for dígito
